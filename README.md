# Налоги РК — тренажёр

Telegram Mini App для подготовки по базе вопросов: темы, тренировки, экзамен, карточки, все вопросы, разбор ошибок и личная статистика.

Прогресс хранится отдельно для каждого пользователя в Telegram CloudStorage. При открытии вне Telegram страница использует хранилище браузера.

## Публикация

В репозитории откройте **Settings → Pages** и в разделе **Build and deployment** выберите **GitHub Actions**. Рабочий процесс из `.github/workflows/deploy.yml` публикует страницу при изменении ветки `main`.

Адрес приложения: https://balkovoy99.github.io/nalogi-rk-test-2026/

В репозитории лежит самодостаточная страница `index.html`; токен Telegram-бота сюда не добавляйте.
